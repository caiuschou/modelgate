## 一、产品是什么

ModelGate 是面向开发者与团队的 **LLM 统一接入网关**：对客户端暴露 **OpenAI 兼容 API**，将请求转发至配置的上游模型服务，并在网关侧提供 **账户、API 密钥、调用审计** 等管控能力。部署者可自建实例，在**实例范围内**管理用户与策略。

---

## 二、当前版本的核心原则

### 2.1 账户与团队资源边界

- **个人默认：** 未加入团队上下文时，API 密钥、控制台可见审计等仍以 **当前用户** 为边界（个人密钥 `team_id` 为空）。
- **团队（已实现）：** 团队作为 **可选** 协作与密钥空间；成员、角色（owner/admin/member）、邀请与 **团队级 API 密钥**、按 `X-Team-Id` 筛选的审计。见 [团队与成员开发方案](../development/teams-and-members-implementation.md) 与 [交互规格](../design/interaction/teams-and-members.md)。
- **不包含（仍不在范围）：** 组织级计费 / 多租户 SaaS 运营后台、企业 SSO、按邮箱域自动入组织等（路线图级）。

若未来调整团队与个人的数据模型，仍可能产生迁移成本；以 [实现状态](../implementation-status.md) 为准。

### 2.2 实例级隔离

- **自建部署：** 每一个独立部署的 ModelGate **实例**拥有独立的数据库与用户空间；实例之间无联邦账户。
- **多租户（词汇澄清）：** 文档历史上「多租户」若指 **SaaS 上多个客户共享一套代码**，由**部署拓扑**与**运营方**决定；**不是**指产品内置「组织树下多级租户 + 成员协作」模型（当前未实现）。

### 2.3 内测与注册

- 注册受 **邀请码** 等与部署配置一致的策略约束（见 [功能详解 — 用户注册](features.md) 与 [注册页交互](../design/interaction/register.md)）。
- **不包含：** 企业 SSO、按邮箱域自动入会、SCIM 等（路线图级能力）。

## 三、v1 范围摘要

| 维度 | 纳入当前开源实现 | 仍不纳入 / 后续 |
|------|----------------|----------------|
| 身份 | 单用户注册 / 登录；**可选团队**、成员、邀请（见实现状态） | 企业 SSO、按域自动入组织 |
| 访问控制 | 个人密钥；**团队共享密钥空间**（owner/admin/member）；网关 Bearer 仍为用户密钥 | 复杂自定义 RBAC、跨实例联邦账户 |
| 代理 | OpenAI 兼容 Chat 等（以实现状态为准）；单上游为主 | 完整多供应商控制台与调度（**暂缓**） |
| 可观测 | 审计（个人或按 `X-Team-Id` 团队视图） | 组织级报表合并（多团队合一的商务视图） |
| 控制台 | 日志、密钥、统计等（**前端**团队切换器 / 成员页可仍待补充） | — |

未在「纳入」列逐项验收的能力，默认视为 **P1+ 或规划中**，以 [实现状态](../implementation-status.md) 为准。
