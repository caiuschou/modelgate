## 二、维护约定（简）

1. **合并代码或交付功能后**，更新 [实现状态](../implementation-status.md) 与 [前端开发计划](frontend-development-plan.md) 第三节对应行的「状态」。
2. **大范围排期变更**（例如砍掉或恢复一整块功能）：修改前端开发计划的里程碑（第二节）与概述（第一节），并在修订说明中留一行日期与原因。
3. **后端接口** 以 [开发 API](api.md)（`src/routes.rs` 对照）为准；计划文中的「待补齐 API」仅作排期提示，**不替代** api.md。
